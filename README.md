# ListaExerciciosJava

Exercícios práticos de **Java** organizados por tópico, do básico ao intermediário.

---

## Estrutura

| Pasta | Conteúdo |
|-------|---------|
| `01_OlaMundo` | Hello World, estrutura básica de um programa Java |
| `02_Variaveis` | Tipos de dados, declaração, casting |
| `03_InterpolacaoConcatenacao` | String.format, concatenação com + e StringBuilder |
| `04_ObjetosArrays` | Arrays, ArrayList, HashMap |
| `05_OperadoresRelacionalIgualdade` | ==, equals, compareTo |
| `06_OperadoresLogicos` | &&, \|\|, !, operador ternário |
| `07_EstruturasCondicionais` | if/else, switch |
| `08_EstruturasRepeticao` | for, while, do-while, break, continue |
| `09_Funcoes` | Métodos, parâmetros, retorno, sobrecarga |
| `10_ClassesMetodos` | Orientação a Objetos — classes, construtores, encapsulamento |
| `11_TypeScript` | Comparativo Java vs TypeScript |
| `12_Exercice` | Desafios práticos mistos |

---

## Como rodar

```bash
# Compilar
javac 01_OlaMundo/OlaMundo.java

# Executar
java -cp 01_OlaMundo OlaMundo
```

Ou abrir no **IntelliJ IDEA** ou **VSCode** com a extensão Java.

---

## Por que Java para QA?

Java é a linguagem base de:
- **Appium** — automação de testes mobile (Android/iOS)
- **Selenium WebDriver** — automação de browser clássica
- **JUnit / TestNG** — frameworks de testes unitários

Dominar Java abre as principais ferramentas de QA Automation do mercado.
